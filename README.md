# hud-manager
A real-time system resource monitor built with JavaFX and OSHI. Features a semi-transparent floating UI.

## Features
* 🚀 **Real-time monitoring** of CPU and RAM usage.
* 🖥️ **Transparent UI**: Stylish neon-green design that floats above all windows.
* 🏗️ **OOP Architecture**: Modular system allowing easy addition of new monitors (GPU, Network, etc.).
* 🛡️ **OSHI Powered**: Reliable hardware data fetching.

## Technologies
* Java 17+
* JavaFX (UI)
* OSHI (Hardware stats)
* Maven (Dependency management)
